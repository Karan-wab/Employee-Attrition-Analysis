# Employee-Attrition-Analysis
# Employee Attrition Analysis & Prediction Dashboard

## 1. Project Goal
The primary goal of this project is to analyze the factors contributing to employee attrition and to build a predictive model that can identify high-risk employees. The final deliverable is an interactive Power BI dashboard designed to provide actionable insights to the HR department for improving employee retention.

---

## 2. Key Features
* **Exploratory Data Analysis (EDA)**: In-depth analysis to identify the key drivers of employee turnover.
* **Predictive Modeling**: An XGBoost classification model trained to predict the probability of an employee leaving.
* **Risk Scoring**: Each employee is assigned an "Attrition Risk" score, enabling proactive intervention.
* **Interactive HR Dashboard**: A Power BI dashboard with KPIs and visualizations for monitoring and analyzing attrition trends.

---

## 3. Tech Stack & Tools
* **Data Analysis & Modeling**: Python, Pandas, Scikit-learn, XGBoost
* **Data Visualization**: Matplotlib, Seaborn
* **Dashboarding**: Microsoft Power BI

---

## 4. File Descriptions
This repository contains the following files:

* `WA_Fn-UseC_-HR-Employee-Attrition.csv`: The raw, original dataset used for analysis and training.
* `Employee Attrition Analysis.ipynb`: A Jupyter Notebook containing all the Python code for data cleaning, exploratory data analysis, and building the XGBoost predictive model.
* `employee_attrition_with_risk.csv`: The output dataset containing all original employee data plus a new `Attrition_Risk` column generated by the model. This file is the direct source for the Power BI dashboard.
* `HR Attrition KPIs Dashboard.pbix`: The interactive Power BI dashboard file.

---

## 5. How to Use

### A. Running the Analysis
1.  Ensure you have Python and the necessary libraries installed (`pandas`, `scikit-learn`, `xgboost`, `jupyter`).
2.  Open the `Employee Attrition Analysis.ipynb` file in Jupyter Notebook or JupyterLab.
3.  Run the cells sequentially to perform the data analysis and generate the `employee_attrition_with_risk.csv` file.

### B. Viewing the Dashboard
1.  You must have **Microsoft Power BI Desktop** installed.
2.  Open the `HR Attrition KPIs Dashboard.pbix` file.
3.  The dashboard will load with all the data and visuals. You can interact with the slicers and charts to filter the data and explore insights.

---

## 6. Key Insights from the Analysis
The analysis identified several strong predictors of employee attrition:
* **Overtime**: Employees who work overtime have a dramatically higher attrition rate (**30.5%**) compared to those who do not (**10.4%**).
* **Job Role**: The **Sales Representative** role has an extremely high turnover rate of nearly **40%**.
* **Marital Status**: **Single** employees are far more likely to leave (**25.5%**) than their married or divorced colleagues.
* **Monthly Income**: Attrition is heavily concentrated among employees in the **lowest salary brackets**.

---

## 7. Dashboard Overview
The Power BI dashboard provides a comprehensive view of employee attrition with the following key components:

### KPIs
* **Overall Attrition Rate**
* **High-Risk Headcount** (Number of employees with a risk score > 70%)
* **Percentage of Workforce at Risk**

### Visuals
* **Table of High-Risk Employees**: A filterable list of employees predicted to be at high risk of leaving, along with their department, job role, and risk score.
* **Attrition by Job Role & Department**: Bar charts identifying which teams are most affected.
* **Risk Score vs. Monthly Income**: A scatter plot showing the strong correlation between low pay and high attrition risk.
* **Interactive Slicers**: Filters for Department, Job Level, and other demographics to allow for deep-dive analysis.
